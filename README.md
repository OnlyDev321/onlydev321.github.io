The personal portfolio of **Tran Hau (김진호 / OnlyDev)**, a Full-Stack Software Engineer & UX/UI Designer studying at **Soongsil University** in Seoul, South Korea. A fast, responsive single-page application built with **React 19, TypeScript, and Vite**, styled with **Tailwind CSS v4**, animated with **Framer Motion** and **Lenis** smooth scroll, with a lazy **Three.js** hero shader in dark mode.


> One disciplined accent, self-hosted variable fonts, a pinned horizontal work reel, a command palette, a magnetic cursor, focus-trapped overlays, and a complete reduced-motion baseline. Zero backend, all static, and tuned for search engines and AI answer engines alike.

## ✨ Features

| | Feature | Description |
|---|---|---|
| ⚛️ | **React 19 + React Compiler** | Latest React with the compiler on for automatic memoization |
| 🅰️ | **Self-hosted variable fonts** | Bricolage Grotesque, Geist, Geist Mono & Instrument Serif as same-origin `woff2` (no third-party round trip) |
| 🎞️ | **Kinetic work reel** | A pinned horizontal scroll reel on desktop that degrades to a native scroll-snap strip on touch / reduced-motion |
| ✨ | **Disciplined motion** | Scroll-linked reveals, one marquee, scroll-velocity skew, and a circular View-Transitions theme reveal |
| ⌨️ | **Command palette** | Fuzzy `⌘K` navigation with full keyboard support and focus management |
| 🧲 | **Magnetic cursor + scroll progress** | Tactile pointer with an accent-tinted snap ring, plus a live reading-progress bar |
| 🌗 | **Light default + dark parity** | Persistent theme via `useTheme`, both AA-contrast, with an anti-flash inline boot script |
| ♿ | **Accessible by default** | Focus-trapped/scroll-locked overlays, validated contact form, semantic headings, full reduced-motion fallback |
| 🧩 | **Data-driven content** | Projects, resume, and process live in typed `src/data` modules; edit data, not markup |
| 🔍 | **SEO + GEO ready** | Sitemap, `robots.txt` (AI crawlers allowed), web manifest, JSON-LD (Person, ItemList, FAQ, WebPage + speakable), a PNG Open Graph card, and an `llms.txt` for LLM discoverability |
| 🚀 | **Performance-first** | Lazy + gated WebGL, `content-visibility`, GPU-only animation, no scroll listeners, code-split bundles |

## 🚀 Getting Started

### Prerequisites

- **Node.js** >= 20 (required by Vite 8)
- **npm** (this project uses `package-lock.json`)

### Installation

```bash
git clone https://github.com/OnlyDev321/onlydev321.github.io.git
cd onlydev321.github.io
npm install
```

### Run the dev server

```bash
npm run dev
```

Vite starts a local dev server with hot module replacement. Open the printed `localhost` URL.

---

## 📖 Usage

Scripts (defined in `package.json`):

```bash
npm run dev       # Start the Vite dev server with HMR
npm run build     # Type-check (tsc -b) and build for production into /dist
npm run preview   # Preview the production build locally
npm run lint      # Lint the codebase with ESLint
npm run deploy    # Build and publish /dist to GitHub Pages (gh-pages)
```

### Make it your own

Content is fully data-driven. Update the typed modules in `src/data/` instead of touching components:

```ts
// src/data/projects.ts — featured + secondary projects (the source of truth)
// src/data/resume.ts   — experience, education, certifications, skills
// src/data/process.ts  — the "how I work" steps
```

The binding visual contract lives in [`docs/design-system.md`](docs/design-system.md), and every token is defined in `src/index.css`.

## 🔍 SEO & AI discoverability

Built to be found by humans on search engines and by LLMs in AI answer engines:

- **Structured data (JSON-LD):** `Person`, `WebSite`, `WebPage` (with `speakable`), `ItemList` of projects, `BreadcrumbList`, and an `FAQPage`.
- **`llms.txt`** at the site root: a clean, citable markdown summary for ChatGPT, Perplexity, Claude, and Google AI.
- **`robots.txt`** explicitly allows major AI crawlers (GPTBot, ClaudeBot, PerplexityBot, Google-Extended, and more).
- **Open Graph + Twitter cards** with a rendered **PNG** card (universally supported by social and AI scrapers).
- **`sitemap.xml`**, canonical + `hreflang`, `rel=me` entity links, a web manifest, and a JS-free `<noscript>` fallback.
- Self-hosted fonts and a lazy, gated WebGL layer keep Core Web Vitals fast, which is itself a ranking signal.
